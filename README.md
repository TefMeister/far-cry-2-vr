# far-cry-2-vr

One repo per game (consolidated 2026-08-30 from this project's former six-repo
set; every folder below was its own repo and carries its full git history).

| Folder | What lives here |
| --- | --- |
| [`mod/`](mod/) | Release packaging and player-facing docs. Releases themselves are on this repo's Releases page. |
| [`dev-archive/`](dev-archive/) | The live mod source, tools, and recon evidence. |
| [`modding-notes/`](modding-notes/) | Dated ledger of findings, decisions, and lessons. |
| [`engine-research/`](engine-research/) | Engine dossier and playbook for this game's engine. |
| [`external-research/`](external-research/) | Curated public research: sources, techniques, prior art. |

Shared, cross-game knowledge lives in
[flat-to-vr-cross-engine-research](https://github.com/TefMeister/flat-to-vr-cross-engine-research)
and [flat-to-vr-RE-toolkit](https://github.com/TefMeister/flat-to-vr-RE-toolkit).
Account map: [TefMeister/INDEX.json](https://github.com/TefMeister/TefMeister).

Personal, non-commercial fan modding; no original game assets are redistributed.
See CONTRIBUTING.md / CREDITS.md for terms and credits.
